# Halo — Sprint Reflections

A 16-slide presentation deck for the Halo sprint.

## Live

- **GitHub Pages:** https://jarmcc.github.io/halo-presentation/
- **Vercel:** https://halo-presentation.vercel.app/

## Presenting

A full presenter script with timings and handoffs is in [`presentation-script.md`](presentation-script.md).

- **Right arrow / Space** — next point
- **R** — switch between slide and scroll view
- **S** — speaker notes (requires the local notes server)

To use speaker notes, run `node server.mjs` and open http://127.0.0.1:4173, then press `S`.

## Deploying

- **GitHub Pages** deploys automatically on every push to `main` (serves the repository root).
- **Vercel** deploys with `vercel deploy --prod`.
